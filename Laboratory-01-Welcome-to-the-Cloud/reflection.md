# Reflection

This laboratory activity helped me learn the basics of Linux and cloud computing. I used the KillerCoda Playground to access a Linux environment and practice using the terminal.

I learned how to create a new user, log in to the account, navigate folders, create directories, and create Markdown files. I also learned how to check the Linux distribution, kernel version, CPU, memory, and disk space.

I also learned how to organize my files and create a GitHub repository for my Cloud Computing Portfolio. I learned that GitHub is useful for storing, organizing, and documenting my laboratory activities.

At first, some Linux commands were difficult to remember, but I was able to understand them by practicing and following the instructions.

Overall, this activity gave me a better understanding of Linux, GitHub, and basic cloud computing tasks. I believe these skills will help me in the next laboratory activities.
