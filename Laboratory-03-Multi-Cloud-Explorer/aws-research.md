
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform from Amazon. It provides many online services that people and companies can use without buying their own servers. AWS can be used for websites, applications, databases, storage, and other IT needs.

## Global Infrastructure

AWS has data centers in different parts of the world. These are grouped into Regions and Availability Zones. This allows companies to choose a location for their applications and helps make their systems more available.

## Cloud Management Console

The AWS Management Console is a website where users can manage their AWS services. Users can create servers, check storage, manage accounts, and monitor their cloud resources from one place.

## 4 Core Services

### 1. Amazon EC2

EC2 provides virtual computers that can run applications and websites.

### 2. Amazon S3

S3 is used to store files and other types of data in the cloud.

### 3. Amazon VPC

VPC allows users to create a private network for their AWS resources.

### 4. AWS IAM

IAM manages users and permissions. It controls who can access AWS resources.

## 3 Advantages

1. **Many Services** – AWS has many services for different IT needs.
2. **Easy to Scale** – Resources can be increased or reduced when needed.
3. **Global Reach** – AWS has infrastructure in many locations around the world.

## Typical Enterprise Use Cases

Companies can use AWS for website hosting, mobile applications, data storage, database systems, backups, and business applications. It can also help companies move their existing systems from local servers to the cloud.
