# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud platform created by Microsoft. It allows users and companies to use computing, storage, networking, databases, and other services through the internet. Azure is also useful for organizations that already use Microsoft products.

## Global Infrastructure

Azure has data centers and cloud regions in many parts of the world. These locations allow companies to choose where their applications and data will run. Using different locations can also help improve availability and performance.

## Cloud Management Console

The Azure Portal is the main website used to manage Azure services. Users can create virtual machines, manage storage, check resources, and control other cloud services from the portal.

## 4 Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can run Windows or Linux.

### 2. Azure Blob Storage

Blob Storage is used to store files, images, videos, backups, and other data.

### 3. Azure Virtual Network

Azure Virtual Network allows users to create a private network for their cloud resources.

### 4. Microsoft Entra ID

Microsoft Entra ID manages users, identities, and access to resources.

## 3 Advantages

1. **Microsoft Integration** – Azure works well with Microsoft products and services.
2. **Scalability** – Resources can be changed based on the needs of the organization.
3. **Enterprise Support** – Azure has many services designed for large organizations.

## Typical Enterprise Use Cases

Organizations can use Azure for Windows Server, business applications, databases, websites, backups, virtual desktops, and hybrid cloud systems. It is especially useful for companies that already use Microsoft technologies.
