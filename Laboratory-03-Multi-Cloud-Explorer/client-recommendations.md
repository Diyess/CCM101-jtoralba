# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Scenario

A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.

### Recommended Platform: AWS

I recommend AWS because the startup has a limited budget but expects its application to grow. AWS has many cloud services that the company can use as it becomes bigger. The startup can begin with the resources it needs and increase them when more users join. This can help the company avoid buying expensive physical servers at the start.

### Recommended Services

* **Amazon EC2** – Used to run the mobile application's backend.
* **Amazon S3** – Used to store files, images, and other data.
* **Amazon RDS** – Used to manage the application's database.

## Client B – University

### Scenario

A university already uses:

* Windows Server
* Microsoft 365
* Active Directory

The university wants to migrate some services to the cloud.

### Recommended Platform: Microsoft Azure

I recommend Microsoft Azure because the university already uses Microsoft technologies. Azure works well with Windows Server, Microsoft 365, and Active Directory. This can make the migration easier for the university. It can also help the university manage its existing systems together with its cloud resources.

### Recommended Services

* **Azure Virtual Machines** – Used to run Windows Server workloads.
* **Microsoft Entra ID** – Used to manage users and access.
* **Azure Blob Storage** – Used to store files, documents, and backups.

## Client C – AI Research Company

### Scenario

A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

### Recommended Platform: Google Cloud Platform

I recommend Google Cloud Platform because the company focuses on Artificial Intelligence and Machine Learning. Google Cloud provides services that can support AI projects and high-performance workloads. It also provides tools for running applications with Kubernetes. These services can help the research company build and test its AI applications.

### Recommended Services

* **Compute Engine** – Used for high-performance computing workloads.
* **Vertex AI** – Used to build and work with AI and Machine Learning applications.
* **Google Kubernetes Engine (GKE)** – Used to run and manage container applications.

## Client D – Global E-Commerce Company

### Scenario

A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

### Recommended Platform: AWS

I recommend AWS because the company serves customers from different parts of the world. A global shopping website needs reliable infrastructure that can handle high and changing traffic. AWS provides services that can distribute traffic and increase resources when needed. This can help keep the website available even when many customers are using it at the same time.

### Recommended Services

* **Amazon EC2** – Used to run the company's web and application servers.
* **Elastic Load Balancing** – Used to distribute traffic across servers.
* **Amazon S3** – Used to store website files, images, and other data.
