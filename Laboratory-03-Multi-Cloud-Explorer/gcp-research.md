# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud platform from Google. It provides services for computing, storage, databases, networking, artificial intelligence, and application development. It can be used by both small and large organizations.

## Global Infrastructure

Google Cloud has data centers in different parts of the world. Its infrastructure is divided into Regions and Zones. These locations help organizations run applications closer to their users and improve system availability.

## Cloud Management Console

The Google Cloud Console is a website used to manage Google Cloud resources. Users can create virtual machines, manage storage, check projects, and control other cloud services using the console.

## 4 Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run applications and other workloads.

### 2. Cloud Storage

Cloud Storage is used to store files and other data online.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is used to run and manage container applications using Kubernetes.

### 4. Cloud SQL

Cloud SQL provides managed databases such as MySQL and PostgreSQL.

## 3 Advantages

1. **Strong AI Support** – Google Cloud provides many tools for artificial intelligence and machine learning.
2. **Kubernetes Support** – GCP provides GKE for managing container applications.
3. **Global Infrastructure** – Google Cloud has regions and zones in different parts of the world.

## Typical Enterprise Use Cases

Companies can use Google Cloud for artificial intelligence, machine learning, data analysis, websites, applications, databases, and container-based systems. It is also useful for companies that work with large amounts of data.
